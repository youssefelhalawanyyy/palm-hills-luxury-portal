# Palm Hills Developments — Luxury Resident & Buyer Portal

Autonomous production platform built by **DEPLOY** (deploy.agency) for Palm Hills Developments (Sheikh Zayed).

## Highlights
- **Framework**: Next.js 15 (App Router) + React 19 + Tailwind CSS
- **Database**: Supabase PostgreSQL with strict Row-Level Security (RLS)
- **Payment Gateway**: Central Bank of Egypt certified Paymob Egypt (InstaPay IPN, Meeza & Visa/Mastercard rails)
- **Resident Services**: Visitor QR Gate Pass Generator & Amenity Reservations (Golf & Club)
- **Live Localhost Preview**: http://localhost:3005/portal/proj-palmhills
